# Лабораторная работа №1

## Постановка задачи
Везде в задачах подразумевается, что строка - в алфавите латинских строчных букв, переменная - в алфавите заглавных латинских, строка окружена маркерами начала `^` и конца `$`.
В некоторых задачах также встречаются скобки - это единственный вид скобок, круглые `()`.
Образцы в левых и правых частях правил даются исчерпывающе: `^P1$ = ^P2$`, где `P2` не содержит свежих переменных, не входящих в `P1`.
Подразумевается, что получившиеся системы переписывания строк должны быть эквивалентны системам переписывания образцов именно по модулю слов, имеющих представление `^[a-z]*$` (или `^[a-z]|)|($`, если в условии встречаются скобки).

## Индивидуальный вариант
#5. Произвольный образец, недетерминизм
Дано единственное правило переписывания, левая часть которого может быть какой угодно, а в правой переменные идут в порядке их первых вхождений в левую часть и не повторяются. Сопоставление недетерминированно.

## Пояснения к лабораторной работе
Построение SRS происходит поэтапно:
1. Обёртка переменных в скобки (происходит только если в левой части правила есть переменные)
2. Проверка повторяющихся переменных на совпадание (происходит только если в левой части есть повторяющиеся переменные)
3. При несовпадении восстанавливается исходная строка, далее возврат на этап 1; иначе переход на этап 4
4. Удаление всех символов вне переменных и всех лишних вхождений переменных
5. Добавление символов из правой части правила

### Обозначения:
- `γ`, `β` - произвольный символ `[a-z]`
- `ANY` - любой символ, кроме `|` и `$`
- `([N0)`, `(]N0)` - скобки, ограничивающие первое вхождение переменной `N`
- `([N1_n)`, `(]N1_n)` - скобки, ограничивающие повторное вхождение переменной `N`, `n` - различающий номер
- `λ` - любой из номеров `1_n` для данной переменной
- `(>N?)`, `(<N?)`, `(>N~)`, `(>N~)` - каретки для проверки совпадения экземпляров переменной `N`
- `(γ*)` - произвольный символ, не являющийся открывающейся квадратной скобкой для текущей переменной (текущая переменная определяется кареткой)
- `({Nλ)`, `(}Nλ)` - скобки, указывающие на то, что экземпляр под номером `λ` переменной `N` обработан
- `!` - маркер для проверки текущего символа
- `([Nλ)`, `(]Nλ)` - скобка, ограничивающая повторное вхождение переменной `N` с номером `λ`
- `(<Nβ)` - каретка, сравнивающая соответствующие символы в первом  и повторяющемся экземплярах переменной `N`
- `(<N!)` - каретка, возвращающая знак `!` в первый экземпляр переменной `N`
- `(<Ndone)` - каретка, обозначающая успешное завершение обработки всех экземпляров переменной `N`
- `(>fail)`, `(<fail)` - каретки, восстанавливающие исходную строку при несоответствии переменных
- `(>s-)` - каретка, удаляющая символы вне переменных
- `(>v-)` - каретка, удаляющая символы лишних переменных и закрывающие скобки первых вхождений переменных
- `(>s~)`, `(>v~)` - каретки, проходящие по символам переменной
- `OTHER` - символы, не указанные для `(>v-)` выше
- `(>v+)` - каретка, добавляющая символы из правой части и удаляющая открывающие скобки переменных
- `(<end)` - каретка, возвращающая начало строки
